# Cognizant Digital Nurture 5.0 - Java FSE Deep Skilling

**Author:** Prasath K S

This repository serves as a structured portfolio for the Cognizant Digital Nurture 5.0 Java Full Stack Engineer (FSE) deep skilling program. It demonstrates end-to-end capabilities across the modern software engineering ecosystem.

---


## 📅 Weekly Curriculum & Implementations
### 🔹 Week 1: Core Java & Design
**Technologies:** Java, PL/SQL, JUnit 5, Mockito, SLF4J
* Implemented GoF Design Patterns (Singleton, Factory, Builder, etc.)
* Built Financial Forecasting algorithms using recursion
* Created PL/SQL stored procedures and triggers
* Enforced TDD using JUnit & Mockito
### 🔹 Week 2: Spring Ecosystem
**Technologies:** Spring Core, Spring Data JPA, Hibernate, Maven
* Managed dependencies via Constructor & Setter Injection (IoC)
* Developed Data Access Layers with JPQL and Named Queries
### 🔹 Week 3: REST APIs & Security
**Technologies:** Spring Web, Spring Security, JWT
* Designed HATEOAS compliant REST APIs with Exception Handling
* Secured application endpoints using stateless JSON Web Tokens
### 🔹 Week 4: Microservices
**Technologies:** Eureka Server, API Gateway, OpenFeign
* Built decoupled Employee and Department microservices
* Established Service Discovery and API Routing
### 🔹 Week 5: Frontend Engineering
**Technologies:** React.js, Angular (v20), TypeScript, RxJS, NgRx
* Explored React JS lifecycle and state Hooks
* Engineered an end-to-end Angular Student Course Portal
* Integrated Reactive Forms, HTTP Interceptors, and NgRx

* **Backend Frameworks:** Java, Spring Boot, Spring Web (REST APIs)

* **Microservices Architecture:** Eureka Service Registry, Spring Cloud API Gateway, OpenFeign
* **Security:** Spring Security, JWT (JSON Web Tokens)
* **Frontend Technologies:** React.js, Angular (v20), TypeScript, RxJS, NgRx
* **Testing, Tools & Version Control:** JUnit 5, Mockito, SLF4J, Git, SonarQube (Code Quality)
